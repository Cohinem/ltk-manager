### Added

- Problems: **Meta property type mismatch** now covers the material name that patch 16.22 stores as an 8-byte hash. A skin bin that still holds `StaticMaterialDef.name` as a path, or as a 4-byte hash, is reported, and the fix rewrites it as the 8-byte hash the game reads. A 4-byte hash is repaired only when the Mimir hashtables or the mod's own `hashes/` name its path, because the new hash is computed from the path and not from the old hash.
- Problems: a finding of a patch the installed game has not reached carries no fix until the game reaches it, so a repair never breaks a mod on the patch you play. The rule stays active for the changes the game has taken.
