## Map Preview and Backdrop

- Added a **map backdrop** to the skin preview: Summoner's Rift, Howling Abyss or any other map in
  your install, grouped by map skin
- Maps are drawn with their own materials under a sky, with toggles for particles, structures and
  props
- **Move** the character around the map with a gizmo, it stays on the ground wherever you put it
- `Map`, `MapSkin` and `MapContainer` objects open with a map preview and an **Outliner** for
  hiding chunks
- `.mapgeo` and `.materials.bin` files files open the map preview

## Game Data Declarations

Game bins opened from a project's game files can now be edited. Every edit is written into a
layer's `game_data.yaml` as a declaration, so a mod carries only what it changes and the rest keeps
following Riot's patches.

- **Layer chip** in the bin toolbar picks which layer the edits are declared into
- **Declared rows** get a mark, and hovering one shows the layer and the game's value
- Values, lists, maps, options and pointers can all be edited, with undo and redo
- **Apply diagnostics** show up on the row they belong to, for example a declaration that no
  longer matches the game's copy after a patch
- **Copy as declaration** on any bin row or a whole object, ready to paste into a `game_data.yaml`
- **Copy reference** on one row, then **Paste reference** (or **Merge reference** for lists and
  maps) on another, declares a value that keeps following the game's copy

## Project Editor

- Added **Reveal in Files** to file tabs, jumps to the file's row in the layer or game files it
  came from
- Objects in a bin file are now sorted by class, then by name
- Project files unpacked under their hash name are now found by previews and links

- Scrolling skin textures pause and seek with the animation
